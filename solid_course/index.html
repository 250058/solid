파이썬으로 탐구하는 SOLID 원칙

개념기반탐구학습지 · 3차시(차시당 45~50분). 설명을 읽는 수업이 아니라, 예측하고 · 실행하고 · 분류하고 · 토론하고 · 직접 규칙을 말해 보는 수업입니다.

이 자료는

  • 대상: 파이썬 클래스(class, __init__, 메서드, 상속)를 써 본 학습자
  • 환경: Python 3.12 이상, 표준 라이브러리만 사용. 인터넷 없이 동작합니다.
  • 학습지 사용법: 입력칸에 쓰면 이 브라우저에 자동 저장됩니다. 인쇄(PDF)도 가능합니다. 정답은 학습지에 없습니다. 먼저 스스로 써 보세요.

3차시 탐구학습지

  • 1차시. 변경에 강한 코드
    렌즈: 변경 · SRP, OCP · 카페 주문과 할인 정책
  • 2차시. 코드 사이의 약속
    렌즈: 약속 · LSP, ISP · 새와 펭귄, 복합기
  • 3차시. 의존의 방향과 설계 프로젝트
    렌즈: 의존 · DIP, 종합 · 알림 서비스, 도서관 대출

실행하기

터미널(윈도우는 명령 프롬프트)을 열어 파일을 저장한 폴더로 이동한 뒤 실행하고, # TODO(학생) 부분을 직접 고칩니다. Python 3.12 이상이 필요합니다.

cd 파일을_저장한_폴더
python3 s1_cafe_order.py

윈도우에서 python3가 안 되면 python 또는 py로 실행하세요. 폴더 이동이 어려우면 코드 편집기(VS Code, IDLE 등)에서 파일을 열어 실행해도 됩니다.

설치 없이 브라우저에서 실행하기

학습지(1~3차시)와 사전 읽기 자료(00~06장) 페이지에서는 Alt+P를 누르면 오른쪽에서 Python 실행창이 나옵니다. 다시 Alt+P를 누르면(실행창 안에서는 Esc도 됩니다) 들어갑니다.

  • 코드를 쓰고 ▶ 실행 또는 Ctrl+Enter(F5)로 실행하면 아래 칸에 결과가 나옵니다. input()을 쓰면 입력창이 뜹니다.
  • VS Code와 비슷한 편집기입니다. 구문 색칠, 줄 번호, 자동완성(Ctrl+Space), 괄호 자동 닫기, 주석 토글(Ctrl+/), 줄 복제·이동 같은 단축키를 쓸 수 있고, 전체 단축키는 실행창의 ? 버튼에 있습니다.
  • 오류가 나면 오류 난 줄 번호를 눌러 그 줄로 바로 갈 수 있습니다.
  • mypy 검사(Ctrl+Shift+Enter)로 타입 힌트를 검사합니다. 하위 클래스가 상위 클래스의 약속(매개변수·반환 타입)을 어기면 LSP 위반으로 알려 줍니다. 처음 누를 때 mypy를 설치하느라 20초쯤 걸립니다.
  • 코드 가져오기 목록에서 이 페이지의 본문 코드나 위의 시작 코드 파일, 교재 예제 파일을 골라 불러올 수 있습니다. 코드 조각에 빠진 import 줄(예: from abc import ABC, abstractmethod)은 불러올 때 자동으로 채워지고, Ctrl+Shift+I로 언제든 다시 채울 수 있습니다. 교재(00~06장)에서 본문 코드 전부 이어 붙이기를 고르면 그 장의 예제를 바로 실행해 볼 수 있습니다.
  • 실행창 머리줄에서 편집기 테마(자동, GitHub Light, VS Code Dark, Solarized Light, One Dark, Monokai, Dracula, Nord, 고대비)를 고를 수 있습니다.
  • 코드를 .py 파일로 저장·불러오기(Ctrl+S / Ctrl+O)할 수 있고, 실행창 왼쪽 가장자리와 출력 칸 위쪽 경계선을 끌어 크기를 바꿀 수 있습니다.
  • 실행창에서 고친 코드는 페이지마다 브라우저에 자동 저장됩니다. 실행창을 처음 열 때 Python을 불러오느라 몇 초 걸리고, 인터넷 연결이 필요합니다.
  • 파일 읽기·쓰기는 브라우저 안의 임시 공간에서만 일어나므로, 학습지 시작 코드를 고치고 제출할 때는 위의 터미널 방식으로 실행하세요.
